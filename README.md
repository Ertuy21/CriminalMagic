# МАГ В 2026 — Вайс-Сити

Браузерная 3D-игра (open world / action / RPG) для мобильных устройств и десктопа.
Three.js, сенсорное управление, без обучающих окон.

## Запуск

```bash
npm install          # если node_modules отсутствует
npm run build        # собирает src/*.js в game.js (esbuild)
npm run serve        # http://127.0.0.1:8123
```

Откройте `index.html` через локальный сервер (ES-модули не работают с `file://`).

### Параметры URL

| Параметр | Значение |
|---|---|
| `?play=1` | сразу начать новую игру |
| `?quality=low\|medium\|high\|ultra` | уровень графики |
| `?hour=21.4` | время суток (0–24) |
| `?weather=clear\|rain\|storm` | погода |
| `?cam=beach\|skyline\|street\|aerial\|port\|ritual` | отладочная камера |

## Управление

**Сенсор:** левый стик — движение, правая половина экрана — камера.
Кнопки: атака/магия, прыжок, присесть, контекстное действие.
**Удерживайте** кнопку смены героя (или **свайп вверх по радару**) — колесо персонажей.
**Удерживайте** кнопку способности — радиальное меню магии/оружия.

**Клавиатура:** WASD — движение, мышь — камера, ЛКМ — огонь, E — действие,
Space — прыжок, C — присесть, R — перезарядка, M — карта, Q/Tab — колесо героев,
1–6 — быстрый выбор способности, Esc — пауза.

## Что реализовано

- **Два героя** с мгновенным переключением: Маг (магия, время, иллюзии) и Люсия
  (оружие, взлом, вождение). Второй персонаж живёт под управлением ИИ.
- **Свобода подхода.** В 8 операциях перед штурмом игра спрашивает, как действовать:
  тихо (враги не замечают, бонус за чистоту), громко (больше врагов, розыск и штраф)
  или магией (мана восстанавливается, свой тон сцены).
- **Сюжетные блокировки колеса.** В ключевых сценах доступен только нужный герой;
  игра сама переключает на него и показывает замок в колесе.
- **Скрытность.** Враги имеют конус зрения, слышат бег и выстрелы. Приседание
  снижает заметность, первый удар по неготовому врагу наносит тройной урон.
  Тонкий индикатор заметности появляется только когда вас действительно видят.
- **45 основных операций** в 6 главах, развилки, 4 концовки (возвращение,
  остаться, жертва, скрытая — при связи 80+ и 5 осколках).
- **40 побочных контрактов**: заказные убийства, доставка, гонки, ограбления.
- **8 посещаемых заведений** в разных регионах: мотель, клуб, оружейная,
  закусочная, клиника, мастерская в порту, бар в Амброзии, причал на Кис.
- **Шесть регионов**: Вайс-Сити, Леонида-Кис, Грассриверс, Порт-Геллхорн,
  Амброзия, Маунт-Калага.
- **172 вида фауны** (64 птицы, 50 наземных, 26 морских, остальное рептилии
  и насекомые) с кодексом наблюдений.
- **Распорядок NPC.** У пешеходов есть роль (работяга, турист, курьер, рыбак,
  байкер, студент, охранник, бездельник) и цель, зависящая от времени суток.
  Ночью улицы пустеют, люди собираются у клуба и закусочной.
- **Реакция на преступления**, розыск, смена одежды для сброса идентификации.
- **Транспорт** с повреждениями (деформация, отваливающиеся детали, дым),
  расходом топлива, износом двигателя, багажником для оружия.
- **Погода** влияет на управление: дождь и шторм снижают сцепление и скорость.
- **Графика**: PBR-материалы, динамические тени, IBL через PMREM, bloom,
  вода с отражениями и пеной, дождь, молнии, неон, туман.

## Структура

```
src/main.js        рендер, цикл, качество, сохранения
src/world.js       город, дороги, вода, небо, погода, интерьеры-двери
src/characters.js  модели героев, толпа, фауна
src/gameplay.js    герой, камера, бой, магия, транспорт, розыск
src/missions.js    сюжет, подходы, контракты, концовки
src/ui.js          HUD, колесо, радиальное меню, карта, диалоги
src/input.js       сенсор, клавиатура, мышь, жесты
src/vehicles.js    физика и повреждения транспорта
src/fx.js          частицы, трассеры, дождь, взрывы
tools/             отладочные сценарии Puppeteer
```

## Тесты

```bash
npm run serve                     # в отдельном терминале
npm test                          # точки старта, скрытность, реакция NPC
npm run test:campaign             # весь сюжет от 1 до 45
npm run test:systems              # фауна, транспорт, магия, колесо
```

Скрипты в `tools/` запускают игру в headless Chrome и завершаются с кодом 1
при регрессии. `BASE` и `CHROME` можно переопределить через переменные окружения.
